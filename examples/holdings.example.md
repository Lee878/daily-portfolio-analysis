# 持仓档案（示例）

> 复制到 config/holdings.md 后把数字改掉即可。解析规则：
> - 只认二级标题 `## A股持仓` / `## 基金持仓` / `## 港股持仓` / `## 美股持仓`；
>   其它二级标题（如账户总览、变动记录）下的表格不会被当成持仓。
> - 名称带 `~~删除线~~`、或数量/状态列写「已清仓 / 已卖出 / 已离场」，该行视为已清仓，
>   不取证、不入卡片（只允许在跨报告对账里一句话提及）。
> - 基金表 3 列（名称｜金额｜收益）或 4 列都支持。
> - 代码列留空时，A股会用 `NAME:<名称>` 占位，取证会跳过并提示补代码。
