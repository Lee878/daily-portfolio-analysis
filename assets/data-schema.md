# data.json 填写规范（数据驱动渲染）v2.4.0

每轮报告**不写 HTML、不写 CSS、不写卡片函数**，只填一份紧凑 `data.json`；
`scripts/render_report.py` 套固定壳渲染。门禁仍由 `gate_check.py` 机械校验。

**只填文字与结构化字段，证据 ID 直接写在文字里**，如 `[dp-001]`。

---

## 顶层结构

```json
{
  "meta": {
    "h1": "盘前持仓报告 · 2026-10-20 周二",
    "sub": "时段 / 账户说明",
    "coverage": "76",
    "coverage_note": "机械值说明（可留空）"
  },
  "stats": [{"v": "+0.16%", "cls": "up", "k": "上证 3722"}],
  "regime": "S2 中性偏多……可含 <b> 与证据 ID",
  "blocks": [ ... 按出现顺序 ... ],
  "sources_note": "数据源总述",
  "sources": [{"label": "标题", "url": "https://具体文章页"}]
}
```

- `coverage` 填 gate 的机械值；`run_daily` 会再校准，不必精确到小数。
- `stats.cls`：`up` 涨（红）/ `down` 跌（绿）/ `b` 蓝 / `y` 黄。
  历史写法 `g`（涨）/ `r`（跌）仍然有效（渲染器自动映射）。
- `sources.url` 必须是可点开的具体文章页，禁止首页/栏目页；pre/post ≥4 条、noon ≥3 条。
- 顶栏摘要、锚点目录、证据清单**由渲染器自动生成**，不要手工写。

## blocks 类型

| kind | 用途 | 字段 |
|---|---|---|
| `card` | 普通叙述段（对账/新闻/宏观/背景/作战池/缺口） | `h2`(可选), `paras`[文字段] |
| `sectors` | 板块雷达 | `h2`, `items`:[{`cls`: bull/mid/bear, `paras`[]}] |
| `cards` | 持仓/基金/现金/投顾/关注库卡片组 | `h2`, `cards`:[卡片对象] |
| `table` | 操作建议汇总表 | `h2`, `rows`:[{`pos`,`act`,`cond`,`cls`}] |
| `warn` / `buy` | 预警 / 可接回高亮块 | `h2`, `paras`[] |
| `raw` | 特殊 HTML（极少用） | `html` |

窄屏（<600px）下表格自动变"每行一块、带列名"，不需要另做手机版。

## 卡片对象字段

### cn / us（完整股票）

```json
{"type":"us","name":"谷歌-C","code":"GOOG · 10股 · 成本200","chg":"+0.96%",
 "tagcls":"up","act_tag":"持有",
 "concl":"持有观察，AI 云支撑估值 [dp-001]",
 "pos":"现价 340.16，PE 16.9，52周分位 58% [dp-003][dp-009]",
 "bull":"云 AI 收入加速、广告韧性 [nw-001][nw-002]",
 "bear":"资本开支高企、监管扰动 [nw-003][nw-004]",
 "cons":"共识在 AI 变现节奏，分歧在费用投放 [ch-001]",
 "risk":"跌破 MA20 止损，风报比中性 [dp-004]",
 "act":"持有不加仓，回踩 MA20 再评估 [dp-005]",
 "fals":"若云收入增速跌破 20%，逻辑转弱 [nw-003]"}
```

- **`bull` / `bear` 不要写"多方："/"空方："前缀**，渲染器会加。写了会出现"多方：多方："。
- `act_tag` 可选：`加` / `减` / `持有` / `观察`。留空则从 `act` 文本推断（已排除"不加仓"这类否定）。
- `chg` 填带符号的百分比；渲染器按正负自动上色 + 加 ▲▼。
- 章节内唯一 ID ≥4、总引用 ≥6、同一 ID 不得重复 ≥5 次（门禁机械校验）。
- pre/post 多空必须**各有对方没有的独立 ID**。

### etf（杠杆/反向 ETP）

`type,name,code,chg,tagcls,concl,top`(跟踪结构+每日重置耗损),`bull,bear,act,fals`

### fund（场外基金）

`type,name,code,chg,concl,bull,bear,act`

### wl（关注库）

```json
{"type":"wl","name":"英伟达","code":"NVDA","chg":"+1.2%","price":"182","target":"195",
 "qty":"4","stop":"165.75","dist":"距目标 -6.7%，未到价",
 "concl":"…","pos":"…","bull":"…","bear":"…","cons":"…","act":"…","fals":"…"}
```

- 到价：`act` 必须含"可接回"+股数+止损+证伪，或明确"先别接"。
- 未到价：**禁止**出现"可接回/买入"。
- 满 4 周未到价：`concl` 或 `act` 要提示"重新评估、重定低位目标价"。

### sgov / advisory

`sgov`：`name,code,chg,concl,bull,bear,act`
`advisory`：`name,code,note`（仅列示，不评分）

## 渲染器自动做的事（不要手工重复）

| 自动生成 | 说明 |
|---|---|
| 常驻顶栏 | Regime 摘要 + 覆盖率 + 今日动作（从卡片 `act` 提取前 4 个） |
| 锚点目录 | 卡片 ≥3 张时出现，手机上一行横滑 |
| 卡片头 | 名称/代码/涨跌（红涨绿跌）/动作徽章 |
| 多空双栏 | 桌面左右并排，手机上下堆叠（多方在上） |
| 折叠 | 市场位置/共识/证伪/证据默认收起；**桌面 ≥900px 自动全展开** |
| 证据清单 | 每张卡底部列 ID + 级别 + 来源 + 可点链接 |
| 表格适配 | 窄屏自动堆叠并显示列名 |
| 免责 / 版本条 / 门禁签名 | 由 `run_daily.py` 注入 |

## 硬红线（与门禁一致，渲染器不放松）

- 卡片集合严格等于 holdings 在册持仓；已清仓标的只在对账段一句话提及。
- 每条论点挂真实存在的证据 ID；P4 不得单独支撑核心结论。
- 必须含：覆盖率横幅、Regime 条、板块雷达、完整卡片、缺口披露（"我不确定的是"）、来源折叠、免责。
- 不写期权/VIX/IV/PCR 策略板块。
- 缺数据如实写进 gaps，禁止编造、禁止占位值。
