# Debate Protocol

多空辩论和风控辩论的具体执行流程。

## 多空辩论流程

> 前提：证据门已 PASS，证据 JSON 中已有数据点（dp）、新闻（nw）、产业链笔记（ch）。
> **双方每条论点必须挂证据 ID**，形如"铜库存连续三周下降，支撑铜价 [dp-007][nw-002]"；
> 没有 ID 的论点按空喊口号处理，研究主管直接删除。禁止引用证据文件中不存在的 ID（报告门会核验）。

### 第 1 轮：各自陈述

**多头研究员**：
1. 阅读证据 JSON 与全部五份分析师报告
2. 从中提取所有支持看多的证据，整理成 3-5 条核心论点，每条挂 1 个以上证据 ID
3. 预测空方会提出什么反对意见，准备反驳
4. 输出结构化的多方论点

**空头研究员**：
1. 阅读证据 JSON 与全部五份分析师报告
2. 从中提取所有看空的风险，整理成 3-5 条核心论点，每条挂 1 个以上证据 ID
3. 预测多方会提出什么反对意见，准备反驳
4. 输出结构化的空方论点

### 第 2 轮：交叉反驳

**多头研究员**：
1. 阅读空方在第 1 轮提出的论点
2. 逐条反驳空方的核心论点
3. 补充新的多头论据（如果有的话）
4. 输出反驳稿

**空头研究员**：
1. 阅读多方在第 1 轮提出的论点
2. 逐条反驳多方的核心论点
3. 补充新的空头论据（如果有的话）
4. 输出反驳稿

### 研究主管综合辩论结果

辩论结束后，研究主管需要综合双方观点：

```
【辩论综合】

双方共识（高置信度）：
1. [共识点1]
2. [共识点2]
...

核心分歧点：
1. [分歧点1]
   - 多方观点：...
   - 空方观点：...
   - 分歧类型：事实分歧 / 解读分歧
   - 验证方法：[需要查什么数据才能判断谁对]
2. [分歧点2]
...

我的判断：
[研究主管认为谁更有道理，为什么]
```

## 风控辩论流程

### 第 1 轮：各自独立评估

基于交易员提出的初始交易提案（方向、仓位、入场价），三位风控各自独立评估：

**激进风控**输出：
```
【激进风控评估】
我认为仓位应该比建议的更高，因为：
1. ...
2. ...
主要风险：[激进策略的风险]
```

**中性风控**输出：
```
【中性风控评估】
我认为仓位建议基本合理，调整建议：
1. ...
风险收益比评估：[上行空间:下行空间]
```

**保守风控**输出：
```
【保守风控评估】
我认为仓位过高，应该降低，因为：
1. ...
最坏情况压力测试：[最大亏损]
止损建议：[价格]
离场条件：[什么情况说明看错了]
```

### 第 2 轮：交叉讨论

三位风控互相看到对方的意见后：
1. 激进风控回应保守风控的担忧
2. 保守风控回应激进风控的乐观
3. 中性风控在中间协调，提出折中方案

### 风控综合结论

```
【风控综合结论】
最终仓位建议：[X%]
合理入场区间：[价格区间]
止损位：[价格] —— 依据：[为什么是这个位置]
目标位：[价格] —— 依据：[上行空间测算]
最大可接受回撤：[X%]
必须离场的条件：
1. ...
2. ...
```

## 辩论质量检查清单

辩论结束后，检查是否满足以下要求：

- [ ] 多空双方都有至少 3 条独立的核心论点
- [ ] 双方都没有出现"一方面另一方面"的中立表述
- [ ] **每条论点都挂了证据 ID，且 ID 在证据 JSON 中真实存在**（报告门机械核验）
- [ ] P4 证据没有单独支撑任何论点
- [ ] 核心分歧点被明确识别出来
- [ ] 保守风控提出的止损条件是具体的、可执行的，且有关键价位证据 ID
- [ ] 所有结论都标注了证据强度
- [ ] 证据缺口（gaps）中影响结论的项，已在"我不确定的是"中披露

## 常见误区

1. **不要让多空研究员变成和稀泥**：如果他们开始说"确实有道理但也有问题"，说明立场不够坚定，需要重新强制站队。
2. **不要忽略保守风控的意见**：保守风控的作用就是找最坏情况，如果它的意见被完全忽略，说明风控环节形同虚设。
3. **不要把辩论变成文字游戏**：辩论的目的是发现真实的分歧点，不是比谁口才好。
