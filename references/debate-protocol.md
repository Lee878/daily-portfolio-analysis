# Debate Protocol

多空辩论与风控辩论的执行流程。

## 执行方式：隔离调用（默认）

### 为什么要隔离

同一段对话里先写多方、再写空方，**空方动笔前已经把多方的论证全读完了**。后果有两个：

1. 空方在多方搭好的框架里找余地，反驳被锚定，倾向软化甚至变成"多方观点的折扣版"；
2. 两方共用同一次证据检索，空方引用的是多方那几个 ID —— 看着两边都说了话，其实是同一批材料正反两说。

这不是辩论，是自我辩护。

### 三种模式

| 模式 | 做法 | 用在哪 |
|---|---|---|
| `isolated` | 每只标的开两个独立子代理（多方 / 空方），互不可见；主代理看双方做裁决 | 盘前 / 盘后（标的 ≥ 8 只） |
| `inline` | 同一上下文内角色扮演，先多方后空方 | 仅午间（标的 ≤ 5 只） |

模式由配置决定：读 config/debate.json（自己从 `../config/debate.example.json` 复制一份），模板见 `../config/debate.example.json`。
**读不到配置时按 `isolated` 执行**（宁可慢，不要假辩论）。

为什么午间可以 `inline`：午间只有 5 只左右，上下文短、累积小，隔离要多花约 27% 输入；
而 16-20 只的盘前盘后，隔离反而省 39%-48%（单上下文每轮都要重发前面已分析过的标的，成本按平方涨）。

### `isolated` 的三次调用

对**每只标的**分别做：

1. **子代理 A（多方）**：只给它这只标的的证据文件路径 + 多头角色指令。
   不告诉它存在空方，不给它其他标的的任何内容。
2. **子代理 B（空方）**：同样只给证据 + 空头角色指令。
   **绝不把 A 的输出给 B**，也不告诉它多方说了什么。
3. **主代理裁决**：拿到 A、B 两份文本后，做交叉质询 → 三视角风控 → 终审，结果写进 data.json。

风控三视角（激进 / 中性 / 保守）默认作为第 3 步的内部步骤，不单独开子代理 ——
风控的分歧点主要落在仓位与止损，对上下文污染不敏感，拆开只会增加调用数。

### 禁止的做法

- 禁止在同一段对话里先写多方再写空方。这是 v2.8.0 及以前的 `inline` 老做法，会造成锚定。
- 禁止把 A 的输出贴给 B，也禁止在 B 的提示里复述 A 的观点。
- 禁止让子代理看到其他标的的分析 —— 会造成标的之间的横向锚定
  （比如前面刚论证"半导体景气向上"，后面那只半导体标的的空方就不敢唱反调）。

### 持仓锚定：辩论阶段不要提持仓成本

`isolated` 的前两次调用，把问题问成「**这家公司现在该不该买**」，
**不要告诉子代理你已经持有、成本多少、浮盈亏多少**。

成本与盈亏只在第 3 步裁决时代入，用来判断「加 / 减 / 保持」，不用来判断「好 / 坏」。

理由：模型一旦知道"用户持有"，会系统性偏向"继续持有、不必恐慌"——这是人的处置效应，模型也沾。
它不会明说，体现在语气和结论方向上，**门禁查不出来**，只能靠流程把它挡在门外。

### 一个诚实的限制

隔离是否真的发生，**无法从产物机械验证**。
模型完全可能不开子代理、在原地扮演两方，然后照常输出格式正确的内容。

门禁能做的是近似约束：**多空证据必须不同源**（`../scripts/gate_check.py` 的多空不同源规则，
按域名 / 媒体来源族判定，转载也算同源）。它能抓出"空方抄多方 ID"这种最典型的假辩论，
但抓不出"两方各自独立引证、结论却互相让步"。

所以人工复核时：**看空方有没有提出一个真正会让多方难受的点**，而不是看它有没有挂够 ID。

## 多方（子代理 A）

> 前提：证据门已 PASS，证据 JSON 中已有数据点（dp）、新闻（nw）、产业链笔记（ch）。

1. 只读这只标的的证据 JSON（不读其他标的、不读空方内容）
2. 提取所有支持看多的证据，整理成 3-5 条核心论点，每条挂 1 个以上证据 ID
3. 预判"如果有人要反驳我，会打哪里"，把这几个点先补上证据
4. 输出结构化的多方论点

**每条论点必须挂证据 ID**，形如"铜库存连续三周下降，支撑铜价 [dp-007][nw-002]。
没有 ID 的论点按空喊口号处理，直接删除。禁止引用证据文件中不存在的 ID（报告门会机械核验）。

## 空方（子代理 B）

1. 只读这只标的的证据 JSON（**不读多方内容**）
2. 提取所有看空的风险，整理成 3-5 条核心论点，每条挂 1 个以上证据 ID
3. 特别关注：估值分位、行业景气拐点、技术面破位、股东减持与解禁、财报红旗、
   单一客户或单一品类依赖、政策性风险
4. 输出结构化的空方论点

空方要**主动去找多方不会去看的那部分材料**（减持公告、评级下调、同业比较劣势）。
如果空方引用的 ID 和多方高度重合，说明它没有独立检索，这次辩论作废重跑。

## 裁决（主代理）

### 交叉质询

拿到 A、B 两份文本后，逐条对照：

- 两边对同一个事实的解读是否冲突？冲突的是事实本身还是解读？
- 空方有没有提出多方完全没回应到的点？如果有，多方的逻辑就有缺口。
- 双方论点的证据强度（P1/P2/P3）是否匹配？多方用 P1、空方只有 P4，说明空方没找到硬料。

### 综合输出

```
【辩论综合】

双方共识（高置信度）：
1. [共识点1]
2. [共识点2]

核心分歧点：
1. [分歧点1]
   - 多方观点：...
   - 空方观点：...
   - 分歧类型：事实分歧 / 解读分歧
   - 验证方法：[需要查什么数据才能判断谁对]
2. [分歧点2]

我的判断：
[谁更有道理，为什么]

持仓处置（此步才代入成本与盈亏）：
- 成本 / 现价 / 浮盈亏：[...]
- 建议：加 / 减 / 保持 / 清仓
- 依据：[挂证据 ID]
```

## 风控三视角

基于裁决阶段得出的方向与仓位提案，三位风控各自评估。

**激进风控**输出：
```
【激进风控评估】
我认为仓位应该比建议的更高，因为：
1. ...
主要风险：[激进策略的风险]
```

**中性风控**输出：
```
【中性风控评估】
我认为仓位建议基本合理，调整建议：
1. ...
风险收益比评估：[上行空间:下行空间]
```

**保守风控**输出：
```
【保守风控评估】
我认为仓位过高，应该降低，因为：
1. ...
最坏情况压力测试：[最大亏损]
止损建议：[价格]
离场条件：[什么情况说明看错了]
```

### 风控综合结论

```
【风控综合结论】
最终仓位建议：[X%]
合理入场区间：[价格区间]
止损位：[价格] —— 依据：[为什么是这个位置]
目标位：[价格] —— 依据：[上行空间测算]
最大可接受回撤：[X%]
必须离场的条件：
1. ...
2. ...
```

## 辩论质量检查清单

- [ ] 出现了两个独立子代理（isolated 模式），或显式记录本次为 inline 模式
- [ ] **空方至少有一条论点的证据 ID 是多方没引用的**（独立检索的最低证据）
- [ ] 多空双方都有至少 3 条独立的核心论点
- [ ] 双方都没有出现"一方面另一方面"的中立表述
- [ ] **每条论点都挂了证据 ID，且 ID 在证据 JSON 中真实存在**（报告门机械核验）
- [ ] P4 证据没有单独支撑任何论点
- [ ] 核心分歧点被明确识别出来
- [ ] 保守风控提出的止损条件是具体的、可执行的，且有关键价位证据 ID
- [ ] 所有结论都标注了证据强度
- [ ] 证据缺口（gaps）中影响结论的项，已在"我不确定的是"中披露
- [ ] 辩论阶段**没有**把持仓成本写进提示词（持仓锚定检查）

## 常见误区

1. **不要让多空研究员变成和稀泥**：如果他们开始说"确实有道理但也有问题"，说明立场不够坚定，需要重新强制站队。
2. **不要忽略保守风控的意见**：保守风控的作用就是找最坏情况，如果它的意见被完全忽略，说明风控环节形同虚设。
3. **不要把辩论变成文字游戏**：辩论的目的是发现真实的分歧点，不是比谁口才好。
4. **不要用 inline 冒充 isolated**：格式对、ID 齐，不等于真的隔离过。
   自检方法：这次空方提出的最狠的那个点，是不是一个独立检索才会发现的（比如一条减持公告）？
   如果空方的论点全都能从多方的材料里推出来，那就是假隔离。
5. **不要为了隔离而隔离**：午间 5 只标的跑 inline 是合理的。判断依据是"标的数与累积成本"，不是"哪个听起来更高级"。
