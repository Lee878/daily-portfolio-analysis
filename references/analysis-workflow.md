# Analysis Workflow

完整的四层分析流程详细说明。

## 第零层：市场大环境前置判断（必做）

> 整合自 stock-prompt v8.0.0 市场 Regime 体系。
> 在做任何个股/板块分析之前，先判断当前市场大环境。

### 步骤 0.1：判断市场 Regime 状态
从 S0-S6 七种状态中选择当前最符合的一种，作为所有后续分析的大背景。
详见 [market-models.md](market-models.md) 第一节。

**输出格式**：
```
【市场大环境】
当前Regime：S2 存量震荡
判断依据：
- 指数在20日线附近，偏离度<2%
- 成交量平量，较昨日变化<5%
- 涨跌家数比约1:1，板块快速轮动
先验上涨概率：30%，先验下跌概率：20%
操作基调：高抛低吸，不追高
```

### 步骤 0.2：数据覆盖率（机械值，禁止手算）

覆盖率不由分析师估算，而由门禁脚本从证据 JSON 机械计算：

```bash
python scripts/gate_check.py --report-root <daily-reports> --date <日期> \
    --session <pre|noon|post> --stage evidence
```

输出含每只持仓覆盖率、组合覆盖率、阻断项与警告。分析师只负责把数据**登记进证据文件**
（字段规范见 [evidence-schema.md](evidence-schema.md)），覆盖率以 gate 输出为准，
报告横幅照抄。详见 [evidence-standards.md](evidence-standards.md) 覆盖率审计部分。

---

## 第〇·五层：取证与证据门（不可跳过）

1. scripts/fetch_data.py 批量拉取行情/估值/技术指标，生成每只持仓的证据 JSON 骨架。
2. 五个视角的分析师把采集结果**写入同一份证据 JSON**（data_points / news / chain_notes），
   每条含来源、URL、时间、证据级别；查不到的标 missing 并进 gaps。
3. 运行证据门：**FAIL 禁止开始第一层分析**；50-69% 只给定性结论；<50% 需显式降级。
4. 此后所有视角报告、辩论论点、终审结论引用证据时一律写 ID（`[dp-xxx]`/`[nw-xxx]`/`[ch-xxx]`）；
   **证据文件中不存在的论据，视为不存在，不得进入分析。**

---

## 第一层：5视角并行数据采集

从以下五个视角独立采集和分析数据，每个视角输出结构化报告。**不要合并视角**，保持独立性。
采集动作与证据登记同步进行；下方每个"证据"字段都必须填证据 ID，而不是笼统写"数据显示"。

### 1. 基本面分析师

**职责**：评估公司内在价值、盈利质量、估值合理性

**采集数据**：
- 最新财报：营收、净利润、扣非净利润增速（同比+环比）
- 盈利能力：ROE、ROIC、毛利率、净利率趋势
- 财务健康：资产负债率、流动比率、应收账款周转、存货周转
- 估值水平：PE/PB/PS/EV-EBITDA 历史分位、同业对比
- 现金流：经营现金流/净利润比率、资本开支需求

**输出格式**：
```
【基本面分析】
核心结论：
1. [结论1] —— 证据：[dp-003][dp-009] —— 强度：强/中/弱
2. [结论2] —— 证据：[dp-010][nw-001] —— 强度：强/中/弱
...
红旗信号：[列出发现的风险点，逐条挂证据 ID]
```
（所有 ID 必须已登记在证据 JSON；P4 级 ID 不得单独支撑结论。）

### 2. 情绪分析师

**职责**：判断市场共识与持仓拥挤度

**采集数据**：
- 资金流向：主力净流入、北向/南向资金、融资融券变化
- 分析师评级：买入/持有/卖出比例变化
- 社媒情绪：讨论热度、多空倾向
- 持仓拥挤度：机构持仓变化、持仓集中度

**输出格式**：
```
【情绪分析】
市场共识：[主流观点一句话]
拥挤度判断：拥挤/适中/冷清 —— 依据：[具体数据]
情绪反转信号：[可能的反转迹象]
强度：强/中/弱
```

### 3. 新闻/宏观分析师

**职责**：识别事件驱动与宏观环境影响

**采集数据**：
- 公司公告：最新公告、财报、增减持、股权激励
- 行业政策：监管变化、产业政策
- 宏观数据：利率、CPI、PMI、汇率
- 即将到来的事件：未来1-3个月的关键事件日历

**输出格式**：
```
【新闻/宏观分析】
近期重要事件：
1. [事件] —— 影响：正面/负面/中性 —— 程度：高/中/低
...
宏观环境判断：[对该标的的整体影响]
即将到来的催化剂：[列出未来关键事件]
```

### 4. 技术分析师

**职责**：判断价格位置与趋势阶段，运用量化模型判断市场结构

**采集数据**：
- 价格位置：当前价在历史区间的分位
- 均线系统：与5/20/60/200日均线的关系
- 动量指标：RSI、MACD、KDJ
- 波动率：布林带位置、ATR
- 关键价位：支撑位、阻力位
- **[新增] 二八撕裂指数**：指数涨跌 vs 红盘率对比
- **[新增] 假阳线/假阴线审计**：日内冲高回落幅度
- **[新增] 连板梯队健康度**：最高板数、断层数、晋级率
- **[新增] ATR空间点位**：Pivot/R1/R2/S1/S2

> 以上量化模型详见 [market-models.md](market-models.md) 第二、三、五节。

**输出格式**：
```
【技术分析】
趋势判断：上升/下降/震荡 —— 依据：[具体指标]
关键支撑位：[价格] / 关键阻力位：[价格]
ATR空间：Pivot [X] / R1 [X] / R2 [X] / S1 [X] / S2 [X]

【市场结构审计】
二八撕裂：正常/轻微撕裂/极端撕裂 —— 依据：[红盘率X%]
假阳线：无/疑似/确认 —— 依据：[日内冲高回落X%]
连板梯队：健康/孤桩龙头/崩塌 —— 依据：[最高X板，断层X层]

短期走势判断：[1-2周方向] —— 置信度：高/中/低
```

### 5. 产业链分析师

**职责**：定位价值链位置与供需格局，判断板块生命周期

**采集数据**：
- 产业链位置：上游供应商、下游客户
- 供给端：产能扩张难度、供应商数量、认证周期
- 需求端：下游需求增长驱动因素
- 竞争格局：市场集中度、主要竞争对手
- 议价能力：对上下游的议价能力
- **[新增] 板块生命周期阶段**：启动/强化/加速/分歧/退潮
- **[新增] SEI主线衰竭指数**：0-100分
- **[新增] 中军vs龙头背离**：健康共振/中军出货/龙头溃退
- **[新增] 电风扇过滤器**：有效主线/电风扇乱窜/过渡分歧

> 以上板块量化模型详见 [market-models.md](market-models.md) 第四、六、七节。

**输出格式**：
```
【产业链分析】
产业链位置：[具体环节]
卡点/稀缺性：[该环节是否稀缺/难替代]
供给端：[产能/竞争格局判断]
需求端：[增长驱动力判断]
核心风险：[上下游议价/替代风险]

【板块结构判断】
生命周期阶段：[启动期/强化期/加速期/分歧期/退潮期]
SEI衰竭指数：[X分] —— [动能充沛/良性分歧/严重衰竭/全面退潮]
中军龙头关系：[健康共振/中军出货诱多/龙头溃退掩护]
轮动类型：[有效主线聚焦/电风扇无效轮动/过渡分歧]
```

## 第二层：多空强制辩论

> **证据前置硬约束**：进入本层前证据门必须 PASS。多空双方的每条论点都必须挂证据 ID；
> 没有 ID 的论点视为空喊口号，研究主管有权直接删除。一条论点至少 1 个 ID，
> 关键论点（仓位、止损、证伪条件）至少 2 个不同维度的 ID；P4 只能作线索、不能单独支撑。

### 多头研究员（强制立场）

**角色设定**：你是坚定的多头研究员。你的任务是找出所有支持看多的理由，反驳所有看空的观点。你必须立场鲜明，禁止中立。

### 空头研究员（强制立场）

**角色设定**：你是坚定的空头研究员。你的任务是找出所有看空的风险，反驳所有看多的观点。你必须立场鲜明，禁止中立。

### 辩论轮次

默认2轮：
- **第1轮**：各自陈述核心论点（各3-5条）
- **第2轮**：针对对方论点逐一反驳，补充新论据

### 研究主管综合

辩论结束后，研究主管综合：
```
【辩论综合】
双方共识（高置信度）：
1. [共识点1]
2. [共识点2]

核心分歧点：
1. [分歧点1]
   - 多方观点：...
   - 空方观点：...
   - 分歧类型：事实分歧 / 解读分歧
   - 验证方法：[需要查什么数据才能判断谁对]

我的判断：
[研究主管认为谁更有道理，为什么]
```

## 第三层：三视角风控评估

### 激进风控

**立场**：风险偏好型，更担心踏空而不是亏损

**关注重点**：
- 上行空间有多大？
- 现在不买会不会错过？
- 最大潜在收益是多少？
- 有没有"不进场就踏空"的催化剂？

### 中性风控

**立场**：平衡型，关注风险收益比的对称性

**关注重点**：
- 上涨空间 vs 下跌空间的比值
- 合理的仓位应该是多少？
- 最佳入场区间在哪里？
- 持有多久合适？

### 保守风控

**立场**：风险厌恶型，最担心本金永久性损失

**关注重点**：
- 最坏情况下会亏多少？
- 有没有黑天鹅风险？
- 止损应该设在哪里？
- 什么情况说明我看错了，必须立刻离场？

### 风控综合

```
【风控综合结论】
最终仓位建议：[X%]
合理入场区间：[价格区间]
止损位：[价格] —— 依据：[为什么是这个位置]
目标位：[价格] —— 依据：[上行空间测算]
最大可接受回撤：[X%]
必须离场的条件：
1. ...
2. ...
```

## 第四层：基金经理终审

综合所有分析，输出最终决策报告。必须包含：

1. **市场位置判断**：当前标的处于什么位置？是否已 price in 预期？近期连涨/连跌幅度？
2. **环比/同比对比**：与上期数据、历史类似情况的对比
3. **预期差分析**：市场预期是什么？超预期/低于预期各会怎样？
4. **进场判断**：现在该加/减/观望？风险收益比如何？
5. **具体操作建议**：方向（买/卖/持有）、仓位建议、入场区间、止损位、目标位、持有周期、置信度（不写期权/VIX/IV 策略）

### [新增] 重大事件周：三套 If-Then 情景作战剧本

> 仅在重大事件周（FOMC/CPI/非农/大公司财报）启用。
> 平时没大事不强行套三情景。详见 [market-models.md](market-models.md) 第九节。

**剧本 A：超预期强攻**

- 执行战法：[具体操作]
- 禁忌：[不能做什么]
- 概率：[X%]

**剧本 B：符合预期震荡**
- 触发条件：[具体数据门槛]
- 执行战法：[具体操作]
- 禁忌：[不能做什么]
- 概率：[X%]

**剧本 C：低于预期走弱**
- 触发条件：[具体数据门槛]
- 执行战法：[具体操作]
- 禁忌：[不能做什么]
- 概率：[X%]

### 证据强度与 ID 标注

每个核心判断必须标注证据强度（P1/P2/P3/P4）并挂证据 ID，详见
[evidence-standards.md](evidence-standards.md)。终审输出的操作建议（加/减/观望、仓位、
止损、目标）必须由至少 2 个不同维度的 ID 支撑；若支撑不足，降级为"待验证"而不是硬给建议。
终审后运行报告门（`../scripts/gate_check.py --stage report`），FAIL 不得交付。

详细输出模板见 [output-templates.md](output-templates.md)。
