# 市场量化模型体系

> 本文件整合自 stock-prompt v8.0.0 开源体系，经过适配改造后用于持仓分析报告。
> 所有模型用于辅助判断，不替代多空辩论与风控终审流程。

---

## 一、市场 Regime 七态判断（前置必做）

每次报告开始前，先判断当前市场处于哪种 Regime，作为后续所有分析的大背景。

| Regime 状态 | 核心特征 | 先验上涨概率 | 先验下跌概率 | 操作基调 |
|:---|:---|:---:|:---:|:---|
| **S0 恐慌释放** | 连续大幅缩量暴跌 / 跌停家数激增 / 恐慌指数飙升 | 15% | **60%** | 全面防守，不抄底 |
| **S1 超跌修复** | 情绪冰点后首次反弹 / 底部放量阳线 / 利空出尽 | **40%** | 20% | 谨慎试仓，小仓位 |
| **S2 存量震荡** | 成交平量 / 涨跌比接近1:1 / 板块快速轮动 | 30% | 20% | 高抛低吸，不追高 |
| **S3 趋势启动** | 指数放量突破20日线 / 主线梯队完整共振 | **55%** | 15% | 积极做多，顺势加仓 |
| **S4 趋势延续** | 指数依托5日线放量主升 / 赚钱效应扩散 | **60%** | 10% | 持股为主，回踩加仓 |
| **S5 高位分配** | 放量滞涨 / 龙头连续高位巨量震荡 / 炸板率高 | 25% | 30% | 逢高减仓，不追高 |
| **S6 退潮出逃** | 主线龙头跌停断板 / 连板大幅负反馈 / 亏钱效应蔓延 | 10% | **65%** | 清仓观望，接飞刀必死 |

### 判断方法
1. 看指数位置（20日线上方/下方、偏离度）
2. 看成交量（放量/缩量/平量）
3. 看涨跌家数比、涨跌停家数
4. 看主线板块是强化还是退潮
5. 看北向/主力资金流向

> **白话解释**：就像天气有晴天、阴天、雨天、暴雨天一样，市场也有7种"天气状态"。不同天气穿不同衣服，不同Regime用不同策略。判断错了天气，再好的选股也会亏钱。

## 二、ATR 空间点位计算

### 公式
- **Pivot（多空分水岭）** = (最高价 + 最低价 + 收盘价) / 3
- **R1（第一阻力）** = Pivot + (最高价 - 最低价)
- **S1（第一支撑）** = Pivot - (最高价 - 最低价)
- **R2（第二阻力）** = Pivot + 2 × (最高价 - 最低价)
- **S2（第二支撑）** = Pivot - 2 × (最高价 - 最低价)

### 使用规则
- 价格在 Pivot 上方偏多，下方偏空
- 接近 R1 注意止盈，接近 S1 注意止损
- 突破 R2 说明强势超预期，跌破 S2 说明弱势超预期
- 盘中判断用当日实时高低点，盘前用前一日数据

> **白话解释**：ATR 就像股票的"日常心跳幅度"。知道它每天跳多大，就知道今天涨到哪里算超预期、跌到哪里算破位。

## 三、二八撕裂与假阳线审计

### 二八撕裂指数（Divergence Index）
**判断标准**：
- 指数收涨，但红盘率 ≤ 35%（即65%以上股票下跌）→ **极端撕裂**
- 指数收涨，但中位数涨跌幅 ≤ -1.0% → **权重护盘掩护出货**

**后果**：
- 二八撕裂时，情绪总分强制扣减20分，封顶60分
- 说明涨的只是少数大权重股，大部分人在亏钱
- 这种上涨不可持续，次日大概率补跌

### 假阳线陷阱（Fake Positive Trap）
**判断标准**：
- 开盘价 < 收盘价（收阳线），但日内从最高点回落 ≥ 1.5%
- 或者开盘跳空高开，全天一路走低，收盘价 < 开盘价

**后果**：
- 假阳线说明早盘冲高是诱多，尾盘抛压重
- 情绪总分扣减15分，封顶60分
- 次日大概率低开

> **白话解释**：就像看一个人脸色红润不一定是健康，可能是涂了腮红。指数涨了但大部分股票在跌，就是"假涨"，千万别被骗了。

## 四、主线生命周期与衰竭指数（SEI）

### 板块生命周期五阶段
1. **启动期**：首次放量突破，龙头首板，板块内个股开始跟涨
2. **强化期**：龙头连板，中军（大市值股）放量上涨，梯队完整
3. **加速期**：龙头缩量加速，后排杂毛开始补涨，成交额暴增
4. **分歧期**：龙头开板震荡，中军滞涨，资金开始高低切
5. **退潮期**：龙头跌停，板块内个股大跌，资金全面撤出

### 主线衰竭指数（SEI: 0-100分）
| 分值区间 | 状态 | 操作建议 |
|:---:|:---|:---|
| 0-30 | **动能充沛** | 积极参与，回踩就是买点 |
| 31-60 | **良性分歧** | 持股观望，不追高 |
| 61-80 | **动能严重衰竭** | 逢高减仓，准备切换 |
| 81-100 | **全面退潮踩踏** | 清仓回避，严禁抄底 |

### SEI 评分要素
- 缩量天数（越久越高）
- 龙头与中军背离比率（中军出货越高分越高）
- 断板率（连板股断板比例）
- 炸板率（触板后打开的比例）
- 板块成交额占比（占比越高越拥挤）
- 低位补涨扩散（后排杂毛涨得越多越危险）

> **白话解释**：每个板块都有生老病死。SEI 就是这个板块的"体温+年龄"。刚生完病的（启动期）最值得跟，快寿终正寝的（退潮期）碰都别碰。

## 五、连板梯队健康度

### 梯队结构
- **最高板**：市场最高连板数（如5板、6板）
- **断层**：相邻高度之间缺少中间板（如只有1板和4板，缺2板3板）
- **晋级率**：昨日涨停今天继续涨停的比例

### 健康度判断
- **健康梯队**：最高板≥4板，断层≤1层，晋级率≥30%
- **孤桩龙头风险**：最高板≥4板，但断层≥2层 → 龙头是孤家寡人，随时A杀
- **梯队崩塌**：最高板≤2板，晋级率<20% → 市场无主线，资金无方向

### 使用规则
- 梯队健康时，打板/追涨策略胜率高
- 梯队崩塌时，短线策略全部暂停，只做低吸或观望
- 孤桩龙头出现时，严禁追高后排杂毛

> **白话解释**：连板梯队就像金字塔。底层1板多、中间2板3板有承接、顶层4板5板有龙头，这就是健康的金字塔。如果只有一个孤零零的5板，下面全空了，那就是危楼，随时倒。

## 六、电风扇无效轮动过滤器

### 判断标准
**电风扇行情**：
- 日内4个以上板块轮番拉升，但每个板块涨幅都不大（<2%）
- 涨停股没有明显的板块聚集（分散在十几个不同板块）
- 成交额没有集中在主线板块

### 后果
- 电风扇行情 = 没有主线，资金乱串
- 此时追任何板块都是追高，因为下一秒就切走了
- 实战指令：管住手，严禁盘中追逐任何脉冲题材
- 最佳策略：持股不动，或者空仓等待主线出现

### 有效主线 vs 电风扇
| 特征 | 有效主线 | 电风扇行情 |
|:---|:---|:---|
| 板块数量 | 1-2个核心板块 | 4个以上乱窜 |
| 涨停聚集度 | 60%以上涨停集中在2个板块 | 分散在10+板块 |
| 中军表现 | 大市值股同步放量上涨 | 只有小票乱跳，大票不动 |
| 持续性 | 连续3天以上 | 当天就结束 |

> **白话解释**：电风扇行情就是市场在"吹牛皮"——每个板块都涨一下，但每个都涨不高。这种时候你追哪个，哪个就跌。最好的办法就是关掉电风扇，坐下来等风停。

## 七、中军 vs 龙头背离审计

### 什么是中军和龙头
- **龙头**：小市值、高辨识度、涨得最快、连板的那只（情绪标杆）
- **中军**：大市值、机构重仓、涨得稳、容量大的那只（资金载体）

### 三种背离状态

#### 1. 健康共振（healthy_resonance）
- 龙头涨，中军也涨
- 龙头连板，中军放量突破
- 说明真金白银在买，不是游资自娱自乐
- **结论**：主线健康，可以积极参与

#### 2. 中军出货诱多（core_desertion）
- 龙头还在硬顶连板，但中军已经破位下跌
- 大资金在撤，游资在炒小票
- **结论**：假繁荣，随时崩盘，严禁追高

#### 3. 龙头溃退掩护（leader_collapse）
- 中军还在涨，但龙头已经跌停或大跌
- 说明主线核心已经垮了，中军只是最后挣扎
- **结论**：主线已死，马上清仓

### 判断方法
- 对比板块内龙头股和中军股的5日涨跌幅
- 看成交量：中军放量上涨才是真，缩量上涨是假
- 看资金流向：主力资金是流入还是流出中军

> **白话解释**：龙头和中军就像一对夫妻。老公（龙头）在外面应酬喝酒，老婆（中军）在家安心做饭，这是正常的。如果老公还在外面浪，老婆已经收拾行李要跑了，那这个家就要散了。

## 八、利好透支审计（Catalyst Exhaustion）

### 判断标准
**高透支风险（exhaustion_risk=high）**：
- 板块前期连续上涨 ≥ 3天
- 昨日已经大涨（>3%）
- 隔夜利好全网刷屏（所有财经号都在推）
- 次日大幅跳空高开 ≥ 2.0%

**后果**：
- 潜伏盘太多，利好一出就是兑现时机
- 大概率高开低走，追高者全部被套
- 强制提示：严禁开盘追高，防冲高回落大阴线

**低透支风险（exhaustion_risk=low）**：
- 利好属于底部首发突发催化
- 板块前期没涨过，潜伏盘极少
- 支持竞价达标后积极跟进

> **白话解释**：一个好消息出来之前，股价已经涨了三天了，那这个好消息就是"最后一棒"——知道的人都已经买完了，就等你去接盘。反过来，如果一个没人关注的板块突然出了个大利好，那才是真机会。

## 九、三套 If-Then 情景作战剧本

> 重大事件周（FOMC/CPI/财报）必用，平时可选。

### 剧本 A：超预期强攻（Bullish Breakout）
**触发条件**：
- 核心标的竞价抢筹大幅超预期（GAP>3% 且量比>1.5）
- 大盘平开或高开，无拖累
- 隔夜利好未被充分透支

**执行战法**：
- 打板第一身位先锋，或中军回踩均线低吸
- 仓位可以稍重（正常仓位的1.2倍）

**实操禁忌**：
- 严禁追高无承接的后排杂毛
- 谨防高开低走大阴线

### 剧本 B：平开分歧震荡（Rotational/Range-bound）
**触发条件**：
- 大盘在 Pivot 附近平开
- 两市无极端恶性核按钮
- 情绪中性，不上不下

**执行战法**：
- 在 S1 支撑位低吸核心主线品种
- 等待 9:45（A股）/ 开盘后30分钟 分水岭承接确认
- 仓位保持正常水平

**实操禁忌**：
- 严禁半路追逐脉冲题材
- 不要在 Pivot 上方追涨

### 剧本 C：核按钮退潮防守（Panic/Retreat）
**触发条件**：
- 高位股出现2只以上跌停核按钮
- 第一龙头竞价跳空重挫（>-3%）
- 大盘低开低走，无承接

**执行战法**：
- 全天停止任何新开仓
- 持仓开盘冲高立即减仓/止损
- 现金为王，等待出清

**实操禁忌**：
- 严禁盲目接飞刀
- 严禁加仓摊平成本
- 严禁水下抄底

> **白话解释**：就像出门前看天气预报——说明天晴就带帽（进攻），说明多云就带伞（观望），说明下雨就别出门（防守）。三套剧本就是提前准备好三种天气的应对方案，不用临时慌。

## 十、证据分级标准

| 级别 | 来源类型 | 可信度 | 说明 |
|:---:|:---|:---:|:---|
| **P1** | 官方公告、财报、监管文件、交易所数据 | 最高 | 公司自己发的，最权威 |
| **P2** | 权威财经媒体报道（ Bloomberg/Reuters/新华财经等） | 高 | 主流媒体，基本靠谱 |
| **P3** | 行情软件数据（东方财富/同花顺/腾讯证券等） | 中 | 数据准确，但解读可能有偏差 |
| **P4** | 网络搜索结果、自媒体、论坛、社媒 | 低 | 噪音多，需要交叉验证 |

### 使用规则
- 核心结论必须有 P1/P2 级证据支撑
- P4 级证据只能作为参考，不能单独做决策依据
- 同一事件多个来源报道，只算一个独立证据族
- 来源数量 ≠ 可信度（10个转载同一个公告还是一个证据）

## 十一、数据覆盖率审计

### 覆盖率计算公式
```
Data Coverage = 已验证证据权重 / 计划证据总权重
```

### 覆盖率等级与操作限制
| 覆盖率 | 允许操作 | 置信度上限 |
|:---:|:---|:---:|
| ≥85% | 完整评分，可给具体操作建议 | 高 |
| 70%-84% | 条件化评分，提示数据不全 | 中 |
| 50%-69% | 只给定性判断，不给精确数字 | 低 |
| <50% | 只列已知事实和待补清单，核心结论暂不评级 | 数据不足 |

### 计划证据权重分配（参考）
- 基本面数据：25%
- 技术面数据：20%
- 资金面数据：20%
- 新闻/事件：20%
- 产业链/行业：15%

> **白话解释**：就像拼拼图，拼了85%以上才能看出完整图案。拼了一半就说"我知道这是什么了"，很可能看错。数据不够就老老实实说"我不确定"，别装懂。
