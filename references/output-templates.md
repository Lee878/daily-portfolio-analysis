# Output Templates

各时段报告的标准输出模板。

**核心排序原则：跟着"下一个要开盘的市场"走**——用户马上要交易的市场放最前，已收盘、只作背景的市场后置。详见 SKILL.md「板块排序原则」。

---

## 通用：报告顶部 · 组合总览条（所有时段必含，置于报告最前）

报告开头（一句话结论紧接其后）必须先给一条"账户总览"，让用户打开就知道整体钱在哪、仓位多重：

```
【组合总览】
- 总净资产（人民币口径）：约 X 万元（A股 + 基金 + 盈立）
- 总持仓市值：约 X 万元 ｜ 现金：约 X 万元
- 整体仓位：约 X%（现金约 X%）
- 盈立（主要操作盘）：仓位约 X%，现金约 X 万
- 重点提示：[如"A股已满仓不动，主要操作港美；当前现金约X%，是加仓子弹还是防守垫"]
```

HTML 里用一排 4-6 个迷你卡片横排：总净资产 / 总持仓 / 现金 / 整体仓位% / 组合近期盈亏。金额用约值，汇率换算需标注为估算。A股满仓不动、操作重心在港美这一结构要体现。

---

## 通用：市场大环境条（所有时段必含，紧跟组合总览）

> [新增] 整合自 stock-prompt 市场 Regime 体系。
> 让用户打开报告第一眼就知道今天是什么"天气"。

```
【市场大环境】
- 当前Regime：S2 存量震荡（S0恐慌/S1修复/S2震荡/S3启动/S4延续/S5分配/S6退潮）
- 数据覆盖率：80%（gate_check 机械计算值，逐字照抄，禁止手改）
- 今日基调：高抛低吸，不追高
- 一句话总结：[今天市场大概什么状态，用大白话]
```

HTML 里用一个横向长条卡片，Regime 用颜色区分（S0/S6红色，S1/S3/S4绿色，S2/S5黄色）；
覆盖率旁标注"机械计算"，低于 70% 整条变黄并提示"只给定性判断"。视觉规范见
[report-html-template.md](report-html-template.md)。

## 通用：持仓深度分析卡片结构

每一只持仓（无论 A股/港股/美股）都用以下结构独立成卡片，禁止多只合并。盘前/盘后用完整版，午间用精简版。

### 完整版（盘前/盘后，400-500字/只）

```
### [标的名称]（代码）

**一句话结论**：[买入/卖出/持有/观望]，置信度 [高/中/低]，建议仓位 [X%]。

**市场位置**：
- 当前价格 / 盘前或隔夜涨跌
- 近期涨跌幅：[1周/1月/3月]
- 是否已price in：[是/否/部分] —— 依据：[说明]
- ATR空间点位：Pivot [X] / R1 [X] / R2 [X] / S1 [X] / S2 [X]

**环比/同比 + 预期差**：
- 与昨日/上周同期对比，市场情绪改善还是恶化
- 市场预期是什么，超预期/低于预期各会怎样
- 利好透支审计：[低透支/高透支风险] —— 依据：[说明]

**多空对比（响应式：手机上下，电脑左右）**：
- 多方（绿块）：3条核心理由，每条末尾挂证据 ID 徽标（如 [dp-007][nw-001]），P4 不得单独支撑
- 空方（红块）：3条核心理由，同样挂证据 ID
- 双方共识：[高置信度判断 + 支撑 ID]
- 核心分歧：[最关键争议点]，验证方法（需要查什么数据）
- 完整版每只标的：唯一证据 ID ≥4、引用总次数 ≥6；午间精简版唯一 ID ≥2（报告门机械核验）

**风控评估**：
- 风险收益比：上行 [X%] : 下行 [Y%]
- 止损位 / 目标位 / 合理入场区间（各附依据）
- 板块生命周期：[启动/强化/加速/分歧/退潮]，SEI [X分]

**操作建议**：方向、仓位调整、持有周期、置信度
**证伪条件**：什么情况说明这个判断错了？
```

HTML 实现要点（完整视觉规范见 [report-html-template.md](report-html-template.md)）：
- 多空对比用 CSS Grid，`@media (max-width: 768px) { .bb { grid-template-columns: 1fr; } }` 手机上下堆叠
- 宽度≥768px 自动变两栏左右并排
- 证据 ID 做成小徽标（P1 实心绿/P2 蓝/P3 灰蓝/P4 虚线黄）
- 每只卡片 400-500 字，但篇幅靠证据与推理支撑，不靠注水

### 精简版（午间，150-200字/只）

```
### [标的名称]（代码）
- 上午表现：涨跌幅、成交额/量能变化
- 异动归因：β还是α？用产业链逻辑解释为什么涨/跌
- 多空核心分歧（一句话）
- 午后操作建议：持有/加/减/观望 + 具体价位 + 仓位
```

精简版不要多空双栏，只保留"多空核心分歧一句话"。

## 盘前报告模板（8:30 · A股/港股优先，9:30要开盘）

```
# 盘前持仓报告

## ① 持仓板块雷达 + 新闻（A股/港股优先）

**先归纳持仓板块暴露**，再按三层输出：
1. **我的持仓板块雷达**：逐板块卡片（板块名+所含持仓+利好/利空/分化标签+最新消息+一句结论），覆盖全部持仓板块
   - [新增] 每个板块标注：生命周期阶段（启动/强化/加速/分歧/退潮）+ SEI衰竭指数
   - [新增] 中军vs龙头关系：健康共振/中军出货/龙头溃退
2. **市场热点板块**：4-6个当前资金主攻方向，点明哪些与持仓共振
   - [新增] 标注轮动类型：有效主线聚焦/电风扇无效轮动/过渡分歧
3. **个股/宏观新闻**：4-8张卡片（分类标签+标题+摘要+对持仓影响），美股隔夜作背景、A股港股盘前优先

## ② A股/港股盘前机会（重点）
- 今日重要事件、政策动向、板块轮动预判
- A股/港股持仓盘前分析（逐只，用通用完整版卡片）

## ③ [新增] 三套 If-Then 情景作战剧本（重大事件周必出，平时可选）
> 详见 market-models.md 第九节。
- **剧本A：超预期强攻**（概率X%）：触发条件 / 执行战法 / 操作禁忌
- **剧本B：符合预期震荡**（概率X%）：触发条件 / 执行战法 / 操作禁忌
- **剧本C：低于预期走弱**（概率X%）：触发条件 / 执行战法 / 操作禁忌

## ④ 今日事件日历
- [时间][事件] 重要性（财报/CPI/FOMC/非农）；不写期权策略方向

## ⑤ 宏观环境扫描（背景）
原油/黄金/比特币/美元/美债10年/VIX

## ⑥ 美股隔夜市场总结（背景，后置）
- 三大指数、关键板块、热门个股、中概股
- 美股持仓盘前提示（GOOG/AVGO/AAOI/AMDL逐只卡片，排在A股港股之后）

## ⑦ 观察名单（2-3只，克制写法）
- 明确"现在不买，加入观察池"
- 触发XX条件再考虑，不写目标价
## ⑧ 信息来源折叠区（HTML 末尾，<details>）
## ⑨ 免责声明
## ⑩ 我不确定的是
```

## 快速诊断模板

用户随手问"我这只股怎么样"时，用轻量模式：

```
【结论】[标的] 短期[看涨/看跌/震荡]，建议[操作]，仓位[X%]。

【核心理由】
1. ...
2. ...
3. ...

【主要风险】
1. ...
2. ...

【证伪条件】什么情况说明我错了？
- ...
```
